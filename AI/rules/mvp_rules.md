# MVP Rules

## Principle
Prioritize the smallest improvements with highest visible impact. The portfolio should get better with each change, not bigger.

## Rules

1. **One improvement at a time.** Finish and ship before starting the next.
2. **High-impact visible changes first.** Fixing what recruiters see beats fixing what they don't.
3. **No feature expansion without clear value.** "It would be cool to add..." is not a valid reason.
4. **No fancy additions that distract from core quality.** Animations, transitions, and effects should be subtle. The content is the product.
5. **No polish before clarity and structure.** If the homepage has duplicated sections, fix that before tweaking button shadows.
6. **Ship the fix, not the framework.** Don't build abstractions for one-time changes.
7. **Measure by hiring impact.** Would this change make a recruiter more likely to reach out? If you can't answer yes, deprioritize.

## Priority Order
1. Fix what's broken or misleading
2. Make the strongest content more visible
3. Eliminate redundancy and weak content
4. Improve consistency across pages
5. Polish visual details
6. Add new content or features

## Anti-Patterns
- Adding a dark mode before fixing the homepage duplication
- Building a CMS before strengthening case study content
- Adding JavaScript animations before ensuring all project cards have thumbnails
- Creating a blog section before the About page is trimmed
