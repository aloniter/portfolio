# Portfolio Rules

## Homepage
- Must quickly communicate: who I am, what I do, and why I'm worth interviewing
- Hero should have: role title, one-sentence value proposition, CTA to view work + download CV
- Project grid should show strongest/most relevant projects first
- Current role (SuperPlay) must be visible in the grid
- No duplicated sections — every section should add unique value
- Contact section should state target roles clearly

## About Page
- Must support the professional story, not repeat homepage content
- Should be scannable in 60 seconds
- Strongest section: "Why Product Owner Roles Fit Me" — preserve this
- Photo adds personality — keep it
- Avoid repeating "How I Add Value" from homepage
- Technical Stack section should be brief — recruiters don't read tool lists carefully

## Project Pages (Case Studies)
- Each must feel like a real case study, even if compact
- Follow the Lucky Tower structure (strongest pattern):
  Meta grid → Screens → Product Goal → My Role → Problem → What I Defined → Engineering/QA → Metrics → Iteration → Next Steps → CTA
- Must include at least one visual (screenshot, video, diagram)
- Must include metrics or success criteria
- Must link to live demo where available
- Footer must say "© 2026"

## Visuals
- Support trust, not just decoration
- Screenshots/demos prove the work is real
- Consistent card thumbnails across the homepage grid
- Gallery images should fill their containers — no large empty space
- Videos should have poster attributes for fallback display

## Every Page Should
- Move the viewer toward confidence in my skills
- Have working navigation to all other pages
- Load quickly (no heavy JS, reasonable image sizes)
- Work well on mobile
- Have meta description and OG tags (once added)
