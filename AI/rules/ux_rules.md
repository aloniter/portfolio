# UX Rules

## First Impression
- Homepage must communicate who, what, and why-hire-me within 3 seconds
- Hero text should be scannable without reading every word
- The strongest evidence should be visible without scrolling on desktop

## Hierarchy
- Visual hierarchy must be obvious: title → subtitle → body → actions
- Section headings should create a scannable outline of the page
- CTAs should stand out — primary gets gradient button, secondary gets outline

## Projects Must Be Easy to Scan
- Card grid should present consistent visual weight across all cards
- Each card needs: image/video, badge, title, short description, tags, CTA
- 3 tags per card maximum — don't overload
- "View Case Study →" is the primary action on every card

## Mobile
- Test every change at 375px width (iPhone SE) minimum
- Touch targets: 44px minimum height for all interactive elements
- No horizontal scroll at any viewport
- Text should be readable without zooming (16px base)
- Buttons should stack vertically on small screens

## Reduce Clutter
- No more than 4 items in a horizontal row at any breakpoint
- No decorative elements that don't serve hierarchy
- White space is a feature — don't fill every gap
- If a section doesn't add value, cut it

## Trust and Intentionality
- Everything should look intentional, not accidental
- Consistent spacing, colors, and typography signal competence
- Broken consistency (different footer years, inconsistent card styles) erodes trust
- The site should feel like someone who cares about detail built it
