# Workflow: Full Portfolio Audit

How to run a complete portfolio review using the agent system.

## Steps

### 1. Open and review all pages
Read all 9 HTML files:
- `index.html` (homepage)
- `about.html`
- `lucky-tower.html`
- `merge-lab.html`
- `beat-runner.html`
- `draft21.html`
- `inspector-pro.html`
- `ice-analytics.html`
- `house-party-vr.html`
- `superplay-dice-dreams.html`

### 2. Run product agent on homepage
Provide `AI/agents/product.md`. Evaluate:
- First impression (3 seconds)
- Scanning phase (30 seconds)
- Is the strongest evidence visible?
- Is the visitor journey clear?

### 3. Run UI/UX agent on all pages
Provide `AI/agents/ui_ux.md`. Check each page for:
- Visual hierarchy
- Spacing rhythm
- Card consistency
- Mobile behavior
- Gallery effectiveness

### 4. Run content editor on all copy
Provide `AI/agents/content_editor.md`. Review:
- Voice consistency across pages
- Buzzword creep
- Vague or generic claims
- Duplicate content between pages

### 5. Run portfolio recruiter
Provide `AI/agents/portfolio_recruiter.md`. Get:
- 10-second impression of the homepage
- Case study depth assessment
- Overall positioning clarity
- Would-I-interview verdict

### 6. Check technical quality
- Console errors on all pages
- All media loads
- All links work
- Footer year consistent
- Meta tags present
- Responsive at all breakpoints

### 7. Update audit docs
Write findings to:
- `AI/portfolio_audit.md` — full page-by-page update
- `AI/current_tasks.md` — new or updated task priorities
- `AI/hiring_positioning.md` — any positioning changes needed

### 8. Prioritize
Rank all findings by:
1. P0 — Actively hurting hiring (broken, misleading, missing critical content)
2. P1 — Noticeably weak (thin content, inconsistency, missing features)
3. P2 — Room for improvement (could be better, not hurting)
4. P3 — Minor polish (nice to have)
